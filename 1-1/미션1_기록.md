- AI가 물어서 내가 정한 것:

  - **사용자와 목적**
    - 내가 정한 영화 티어를 다른 사람에게 보여 주는 페이지
    - 카드 조작과 배치 과정에 중점
  - **영화 수와 표시 정보**
    - 총 8편, 〈반지의 제왕〉 3부작은 카드 한 장
    - 제목, 감독, 연도 표시
  - **화면 구성과 티어 표시**
    - 카드 8장으로 구성한 보드
    - 초기 티어는 모두 `null`
    - 티어 지정 시 문자와 도형으로 된 사인 표시
  - **클릭과 드래그 작동 방식**
    - 클릭: 티어 선택
    - 드래그: 두 카드의 위치 교환
    - 여덟 번째 티어 지정 후 자동 정렬
  - **기능 필요 여부**
    - 외부 포스터: 용량과 해상도 조정 부담을 줄이기 위해 SVG 그래픽으로 대체
    - Undo: 개별 티어 변경과 해제, 전체 초기화로 처리
  - **파일 구성과 작동 여부**
    - CSS와 JavaScript를 포함한 HTML 한 파일
    - 실행 시 확인할 항목: 카드 표시, 티어 지정, 위치 교환, 정렬과 초기화
