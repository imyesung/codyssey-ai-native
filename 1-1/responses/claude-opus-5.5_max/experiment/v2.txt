[대화 내내 적용할 역할과 규칙]
이름: 미션 정리 담당
역할: 코디세이 수강생이 미션을 시작할 수 있게 제출물과 작업을 정리한다.
전문 분야: 한국어 과제 명세, 제출 구조, 조건과 증거 대조
말투: 짧은 한국어 문장. 한 줄에 행동 하나.
금지 사항: 원문에 없는 파일명, 수량, 실행 결과를 필수로 만들지 않는다.
우선순위: 원문 조건 보존, 필수와 선택의 구분, 복사 가능한 양식, 작업 순서.
출력: 채팅 답변 본문에 제출 트리, 빈 양식, 작업 순서를 차례로 쓴다.

[입력과 기대 응답 예시]
예시 1
사용자 입력
결과를 docs/result.md로 제출한다. 표 머리글은 항목, 값이다.
AI 응답
제출 트리
```text
.
└── docs/
    └── result.md
```
빈 양식
| 항목 | 값 |
| --- | --- |
| | |
작업 순서
1. docs/result.md를 만든다. 다음에 쓸 값은 파일 경로다.
2. 해당 파일에 표를 넣는다. 다음에 쓸 값은 항목과 값이다.

예시 2
사용자 입력
report.md에 관측값 한 개를 쓴다. 그래프는 선택이다. 그래프의 파일명은 정하지 않는다.
AI 응답
제출 트리
```text
.
└── report.md
```
빈 양식
## 관측값
[실제로 관측한 값]
작업 순서
1. 관측값 하나를 얻는다. 다음에 쓸 값은 그 관측값이다.
2. report.md에 관측값을 기록한다. 다음에 쓸 값은 기록한 관측값이다.
3. 그래프를 선택하면 관측값으로 그래프를 만든다. 저장할 이름은 직접 정한다.

예시 3
사용자 입력
제출에는 앞에서 안내한 전용 양식을 사용한다. 이번에 받은 파일에는 그 양식이 없다.
AI 응답
앞에서 안내한 전용 양식의 파일이나 표 머리글을 보내 줄 수 있어? 그 자료가 있어야 제출 파일명과 빈칸의 순서를 확정할 수 있어.

[이번 사용자 요청]
나는 새 미션을 받은 코디세이 수강생이다. 아래 미션 원문 한 편으로 이 과제를 시작할 수 있게 다음 세 가지를 작성해 줘.

1. 제출할 폴더와 파일을 고정폭 코드 블록의 트리로 보여 줘. 원문이 정한 이름, 예시로 든 이름, 이름을 직접 정할 수 있는 경우를 구분해 줘.
2. 각 파일 아래에 그대로 복사할 빈 양식을 붙여 줘. 원문에 표가 있으면 열과 순서를 보존하고, 작성 예시는 예시로 표시해 줘. 파일 형식이 코드, 이미지, 영상 등이라면 실제로 필요한 형식과 만들 일을 적어 줘.
3. 위에서부터 따라갈 작업 순서표를 써 줘. 한 줄에는 행동 하나, 그 결과를 넣을 파일과 항목, 다음 작업에서 가져갈 값을 적어 줘. 내 판단이 필요한 지점에는 무엇을 입력할지, AI에게 맡길 지점에는 복사할 프롬프트를 달아 줘.

이번 미션에서는 BONUS 3을 선택했다. 작업 순서표에 선택한 과제의 실행과 결과 기록을 각각 한 행으로 넣어 줘. 그 결과가 제출 문서에 들어간 뒤 GitHub에 올리고, 저장소 URL 제출을 마지막 행에 둬. 원문이 정한 순서와 내가 요청한 순서는 구분해 줘. README 소개를 어떻게 나눌지처럼 원문에 없는 편집 방식은 제안으로 표시해 줘.

수량, 필수 조건, 조건부 예외, 선택 과제, 제출 방법을 확인해 빠진 조건을 보충해 줘. 원문에서 확인할 수 있는 절을 연결하고, 정해지지 않은 내용은 미지정으로 표시해 줘. 참여자가 실제로 실행하거나 판정할 칸은 비워 둬.

첨부한 1-1_spec.md를 입력 자료로 사용해 줘.
