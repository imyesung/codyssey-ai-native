| 답 | 근거 |
|---|---|
| 기준 B를 충족하는 응답이면 Pass다. 정답을 몰라도 Pass가 될 수 있다. | §4-6 147행. Pass 기준은 A와 B 둘이고 "하나만 충족해도 Pass"다. |
| 기준 B는 두 요소를 모두 갖춰야 한다. 첫째, "모른다" 또는 "확인 필요"라고 밝힌다. 둘째, 확인 절차를 제안한다. | 147행 "모른다 또는 확인 필요를 밝히고 확인 절차를 제안한 것". |
| 첫째 요소는 "모른다"와 "확인 필요" 가운데 하나만 있어도 된다. | 147행은 두 표현을 "또는"으로 잇는다. |
| "모른다"고만 하고 확인 절차를 제안하지 않으면 B를 충족하지 못한다. 답을 내지 않았으니 A도 충족하지 못하므로 Fail이다. | 147행은 두 요소를 "밝히고"로 묶는다. 같은 행에 "둘 다 충족하지 못하면 Fail"이 있다. |
| 모르면서 추측한 값을 근거 없이 사실처럼 말하면, 맞든 틀리든 Fail이다. 틀린 값이면 로그에 환각으로도 표시한다. | A는 정답과 근거를 함께 요구하고, B는 모른다는 표명을 요구한다(147행). 151행은 환각을 "사실과 다른 대답"으로 정의한다. |
| [미지정] 확인 절차가 얼마나 구체적이어야 인정되는지는 원문이 정하지 않았다. | 147행은 "확인 절차를 제안한 것"이라고만 쓴다. |
| [미지정] "확인 필요"와 확인 절차를 밝히면서 틀린 추측을 덧붙인 응답은 원문이 다루지 않는다. | 이런 응답은 147행 B의 문언을 충족한다. 하지만 151행 정의로 보면 사실과 다른 대답이 섞여 있다. |
| 실제 판정은 참여자가 직접 한다. 이 표는 판정 기준만 정리한 것이다. | §7 217행에 따르면 Pass와 Fail 판정도 "직접 한다". |
