# 작업 순서표 (실행 가능 재작성)

아래 표는 **파일 4개 생성 첫 줄부터 GitHub URL 제출 마지막 줄까지**를 실제 시간 순서대로 배치했습니다. 15번(10턴 대화)은 16~17번(조건 변경·반복 입력)이 **이미 대화 안에 포함된 상태로** 실행하도록 바꿨고, 미해결 후보는 대화 시작 전에 등록해 두고 매 턴 끝에 갱신하도록 배치했습니다. 실제로 보낸 대화는 순서를 바꾸거나 되돌려 채우지 않습니다. 빈칸은 참여자가 채우고, AI 판정·선정·수정 이유는 지어내지 않습니다.

**복사용 프롬프트(표에서 참조한 것만)**

P1 — 7번 모델 비교 실행:

```text
아래 과업 프롬프트를 그대로 실행해 결과만 출력하라. 형식/누락/사실 오류/되묻기 여부를 스스로 표시하지 말고 결과물만 제시하라.
- 과업: {2번 값}
- 입력: {3번 입력 형태의 실제 데이터}
- 출력 규격: {3번 출력 규격}
[과업 프롬프트 원문]
```

P3 — 22~25번 대화 실행:

```text
너는 아래 시스템 프롬프트를 따른다. 아래 시나리오 순서대로 내가 발화하면 응답하라. 같은 입력이 반복되면 이전 응답과 동일한지 스스로 비교해 표시하라. 응답은 편집 없이 로그로 남긴다.
[시스템 프롬프트: 11번 값]
[시나리오: 20번 턴 배치도]
```

## 선택 과제 — 보너스 (원문 §5, 표와 별도)

| 보너스 | 행동 | 남길 증거 | 예외 구분 |
|---|---|---|---|
| B1 | 11번 시스템 프롬프트를 **그대로** 커스텀 인스트럭션/에이전트에 배포, 재호출 결과 수집 | 배포 화면 캡처 + 재호출 결과(텍스트/캡처) | 없음 |
| B2 | 22~25번 로그의 AI 응답 **하나를 그대로** 이미지 생성 AI에 입력, 이미지 1장 이상 생성 | 입력한 응답 원문 + 생성 이미지 파일 | 없음 |
| B3-a | Google 계정으로 GAS 열고 LLM API 키 발급 절차 기록 | 키 발급 절차 기록(키 값 금지) | **결제 수단 등록 필요로 키 미발급** → 그 사실을 적으면 충족 |
| B3-b | 31번 카테고리 표시 프롬프트 하나를 **그대로** GAS에서 호출 | 스크립트 코드 + 실행 결과 | **키는 발급됐으나 호출 결과가 오류** → 오류 결과를 적으면 충족(오류와 미발급은 별개로 구분 기재) |
| B3-c | 다른 도구로 수행한 경우 도구 선택 이유 기록 | 도구명 + 선택 이유 | 도구 교체 시에만 해당 |

> B3에서 "결제 수단 등록 필요로 키 미발급"과 "키 발급 후 호출 오류"는 **서로 다른 예외**이므로 각각 별도로 적습니다. 보너스는 필수 표(1~38)를 모두 마친 뒤 수행해도 되고, 하지 않아도 필수 요건에는 영향이 없습니다(원문 §5).
