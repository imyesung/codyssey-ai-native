# 기획서: 다시 보고 싶은 영화 티어리스트

## 1. 사용자
- **주 사용 대상:** 본인 (개인 감상 기록 및 시각적 정리 용도)

## 2. 웹페이지의 목적
- 8편의 영화를 S, A, B, C 티어로 분류하여 직관적인 티어리스트 형태로 완성.
- 애플(Apple)이나 피그마(Figma) 스타일의 세련된 UI와 물리적인 카드 인터랙션을 통해 시각적, 촉각적(모바일) 만족감 제공.

## 3. 화면과 세부 동작
- **초기 상태:** 티어 표식이 없는 8장의 영화 카드가 화면에 배치됨.
- **티어 기준:**
  - **S:** 꼭 다시 보고 싶은 영화
  - **A:** 다시 봐도 좋을 영화
  - **B:** 기회가 되면 볼 영화
  - **C:** 한 번 본 것으로 충분한 영화
- **인터랙션 (두 가지 방식 모두 지원):**
  1. **드래그 앤 드롭:** 카드를 잡아 원하는 티어 영역으로 끌어다 놓기.
  2. **클릭(터치) 후 팝업 선택:** 카드를 누르면 S, A, B, C 메뉴가 나타나 선택 가능.
- **최종 레이아웃:** 카드가 각 티어에 할당되면서 전통적인 티어리스트(좌측에 등급 색상 라벨이 있는 격자 형태)로 자연스럽게 이동 및 정렬됨.

## 4. 필요한 자료
- **기술 스택:** 순수 HTML, CSS, Vanilla JavaScript (단일 파일 또는 기본 폴더 구조 구동).
- **영화 목록 (총 8편):**
  1. 겨울왕국
  2. 헤어질 결심
  3. 반지의 제왕
  4. 에브리씽 에브리웨어 올 앳 원스
  5. 미스 리틀 선샤인
  6. 내일을 향해 쏴라
  7. 허공에의 질주
  8. 위대한 레보스키
- **이미지 리소스:** 각 영화의 고화질 포스터 이미지 URL (코드 작성 시 웹에서 불러올 수 있는 링크로 직접 삽입).

## 5. 완성 기준 체크리스트
- [ ] 외부 프레임워크 없이 순수 HTML, CSS, JS만으로 완벽히 구동되는가?
- [ ] 모바일 환경에서 터치 및 드래그 동작이 부드럽고 매끄럽게 지원되는가?
- [ ] 드래그 앤 드롭 방식과 클릭 후 선택 방식이 충돌 없이 작동하는가?
- [ ] 카드 선택, 이동, 안착 시 물리적인 느낌의 부드러운 애니메이션(Transition/Spring)이 적용되었는가?
- [ ] 최종적으로 티어리스트 레이아웃으로 직관적으로 완성되는가?
