# 내 영화 티어리스트

## 누가 쓰나

- 나와 영화를 좋아하는 친구들

## 무엇을 하려고

- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.

## 화면과 동작

- 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
- 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- 휴대폰처럼 터치 화면에서는 카드를 0.2초쯤 누르고 있으면 카드가 살짝 들리고, 그대로 끌어 원하는 칸에 놓으면 옮겨집니다. 끄는 동안 손가락이 화면 위나 아래 끝에 가까이 가면 화면이 저절로 스크롤됩니다.
- 제목을 입력하고 ‘추가’를 누르면 아직 안 정한 영화에 카드가 생깁니다.
- 영화 목록과 등급 배치를 브라우저에 자동으로 저장합니다.
- ‘처음으로’를 누르면 처음 영화 목록과 배치로 돌아갑니다.
- 처음 영화 8편이 모두 등급 칸에 들어가는 순간, 팝콘 통 캐릭터가 색종이와 함께 나타나 축하하고 3초쯤 뒤 저절로 사라집니다. 직접 추가한 영화는 이 조건에 넣지 않습니다.

## 필요한 자료

- 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리
- 축하 캐릭터: 직접 그린 팝콘 통 캐릭터. 그림은 HTML 안에 SVG로 넣어 외부 이미지 파일을 쓰지 않습니다.

## 완성 기준

- 영화가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
- ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다.
- 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.
- 빈 제목은 추가하지 않습니다.
- 처음 영화 8편이 모두 등급 칸에 들어가는 순간 축하 애니메이션이 나타났다가 3초쯤 뒤 저절로 사라집니다.
- 축하는 미완성에서 완성으로 바뀌는 순간에만 나옵니다. 완성된 목록을 다시 열거나 등급끼리 옮길 때는 나오지 않고, 한 편을 미분류로 돌렸다가 다시 넣으면 다시 나옵니다.
- 축하 애니메이션이 떠 있는 동안에도 카드 선택, 옮기기, 추가, ‘처음으로’를 그대로 쓸 수 있습니다.
- 축하 화면도 폭이 좁은 화면에서 오른쪽이 잘리거나 가로 스크롤을 만들지 않습니다.
- 기기에서 움직임 줄이기를 켜 두었으면 색종이와 튀는 움직임 없이 조용히 나타났다 사라집니다.
- 축하 기능을 더해도 기존 화면과 동작, 저장 내용은 바뀌지 않습니다.

- 터치 화면에서도 카드를 끌어 놓아 등급을 정할 수 있고, 처음 영화 8편을 모두 정하면 축하 애니메이션이 나옵니다.
- 터치 화면에서 카드를 누르자마자 밀면 평소처럼 화면이 스크롤되고, 끌지 않고 손을 떼면 원래처럼 카드가 선택됩니다.
- 끄는 동안 화면 위나 아래 끝에 가까이 가면 저절로 스크롤되어, 화면 밖에 있던 칸에도 놓을 수 있습니다.
- 칸 밖이나 원래 있던 칸에 놓으면 카드가 이전 칸에 남습니다.
- 컴퓨터의 마우스 드래그와 카드 선택 후 등급 글자 누르기로도 영화를 옮길 수 있습니다.
