# Codyssey Mission AI 활용법

## 선택본과 기획의 기준

2-2의 선택 파일은 GPT-6 Astra가 처음 만든 [미션AI활용법_v1.html](미션AI활용법_v1.html)이다. 2026년 11월 13일 선택 파일을 이 최초본으로 정했다. 이후 화면 크기와 이동 순서, 제목과 원고를 다듬어 미션톤에서 사용한 파일은 `missionthon-ai-tips-yesunglim.html`로 보존돼 있다.

두 AI에 전달한 기준은 [최초 공통 기획서](참고/최초_공통기획서.md)와 [최초 공통 요청](참고/최초_공통요청.txt)이다. 아래에는 그 기획의 목적과 요구사항을 정리하고, 최초본에서 확인한 결과를 덧붙였다.

## 대상과 목적

같은 입학연수 미션을 해 본 코디세이 동료에게 보여 주는 자료다. 발표 중에는 한 사람이 키보드로 화면을 넘긴다. 발표 뒤에는 동료가 같은 파일을 열어 자기 과제와 가까운 사례와 요청문을 찾는다.

먼저 결과를 보여 주고, 다음에 그 결과를 받은 요청문을 읽는다. 수정 전후 녹화에서는 손끝 아래의 칸, 화면에 표시된 테두리, 실제로 저장된 등급을 구별한다. 피드백 도식에서는 확인한 문제와 기획서의 기준, 사용성을 위한 제안을 구별한다. 레퍼런스에서는 실제 페이지의 여백과 이미지 배치를 비교한다.

## 화면과 조작

| 순서 | 화면 | 조작 |
| --- | --- | --- |
| 1 | 제목, 재현 영상과 코드 | ‘놓은 칸과 저장된 칸’, ‘영화 추가’, ‘초기화’, ‘2배 확대’를 고른다. 전후 녹화를 함께 멈추고 재생하며 해당 코드와 원문 링크를 읽는다. |
| 2 | 피드백 도식과 원문 표 | 네 행과 세 열의 관계를 읽고 원문 표를 펼친다. |
| 3 | 레퍼런스 조사 | 여섯 사례의 외부 캡처와 설명, 원문 링크를 읽는다. 요청 3~5에서 조사 방법을 확인한다. |
| 4 | 독립 검사 | 세 판본의 테두리와 저장 결과, 수정 기록과 검사 요청을 읽는다. |
| 5 | 요청문 모음 | 요청문 여섯 개와 공유 지침 네 개를 읽고 개별 또는 전체 복사를 실행한다. |

원기획은 본문에서 방향키로 발표 위치 열한 곳을 이동하고, 좁은 화면에서는 목차를 펼쳐 원하는 절을 찾도록 했다. ‘해설과 함께 읽기’로 읽기 상태를 바꾼다. 실제 최초본에도 발표 위치 열한 곳과 위 다섯 절이 있다.

## 파일과 자료

CSS와 JavaScript, 본문, 코드, SVG 도식, 요청문은 HTML 안에 있다. 여덟 녹화와 여섯 레퍼런스 캡처는 HTTPS 주소에서 불러온다. 외부 연결이 끊기면 영상의 상태 안내와 결과 설명을 읽을 수 있다.

피드백 도식은 기존 `1-3`의 SVG이고 녹화와 비교 코드는 `1-4`의 고정 커밋을 출처로 삼는다. 외부 화면에는 저자, 제목과 원문 링크를 붙였다. 외부 화면의 별도 재배포 허락은 미확인 상태로 기록돼 있다.

## 완료 기준과 확인 결과

1. 네 사례를 고르면 같은 사례의 전후 영상과 코드가 바뀐다. 함께 멈추면 해당 프레임을 유지한다. 11월 13일 선택본의 네 사례에서 이 동작을 확인했다.
2. 요청문 모음에서 개별 문구를 복사하고 원문의 줄바꿈을 보존한다. 첫 요청 205자를 실제 clipboard에서 읽어 원문과 대조했다.
3. 390px 화면에서도 본문과 목차를 이용할 수 있다. 원기획은 본문의 가로 넘침을 막고 도식과 긴 코드를 해당 영역 안에서 읽도록 했다. 선택본의 문서 너비는 390px였다. 두 영상은 약 170px씩 나란히 표시돼 영상 속 글자를 더 크게 읽을 배치를 후속 보완점으로 남겼다.
4. 외부 연결이 끊겨도 본문, 코드, 도식, 목차와 요청문을 이용할 수 있고, 영상 자리에는 상태와 결과 설명을 표시한다.

실제 조작, 예상 결과와 실제 결과는 [제작검증기록](제작검증기록.md)의 세 테스트와 보너스 과제에 정리했다.

## 제작 도구와 검증 방법

최초 후보는 OpenAI Codex의 GPT-6 Astra(`xhigh`)와 Claude Code의 Claude Opus 5.5(`extra`)로 만들었다. 같은 입력으로 생성한 최초 HTML을 비교하고, 선택본의 SHA-256을 원본과 대조했다.

브라우저 비교는 macOS의 Chrome 157.0.8103.51과 Safari 26.5.2에서 수행했다. 좁은 화면과 외부 연결 차단 검사는 Chrome에서 진행했다. 추가 조작과 수치 측정은 Codex가 수행했으며, 선택본 지정과 지인에게 받은 의견은 작성자가 제공했다.
