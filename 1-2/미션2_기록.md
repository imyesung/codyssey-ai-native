# 미션 2 기록

- ChatGPT(GPT-6, Pro) / [대화 공유 링크](https://chatgpt.com/share/6aeadcea-1d00-83e8-bfea-007817c12365)

- 좁혀서 적은 한 문장

  수정 전 시험한 제목 중 공백이 있는 영화 카드는 끌어 놓은 뒤에도 미분류 영역에 그대로 있었지만, 제목에 공백이 없는 '이창'은 이동했다.

- 좁히려고 해 본 것과 결과

  - '센과 치히로'를 추가하면서 드래그 문제를 처음 발견했다.
    기본 목록의 '센과 치히로의 행방불명', '어벤져스: 엔드게임', '토이 스토리'도 끌어 보았다.

  - 이어서 '이창'을 추가해 드래그했다.
    제목에 공백이 있는 영화 카드 4편은 끌어 놓은 뒤에도 제자리에 남았고, '이창'은 이동했다.

- AI가 말한 원인 및 직접 확인 결과

  공백에서 식별값이 잘린다. HTML에서 속성은 버튼 태그 안에 적는 `이름="값"` 형태의 정보다.
  `data-id="센과 치히로의 행방불명"`이라면 속성 이름은 `data-id`이고, 값은 영화 제목 전체다.

  그런데 원본은 값 양쪽의 따옴표가 빠진 `data-id=센과 치히로의 행방불명`으로 만들어졌다.
  브라우저는 첫 공백에서 `data-id`의 값이 끝났다고 읽고, 뒤의 두 단어를 다음 속성의 이름으로 처리했다.

  개발자 도구에서 확인한 버튼의 속성 부분을 줄별로 나누면 다음과 같다.

  ```html
  data-id="센과"
  치히로의=""
  행방불명=""
  ```

  `치히로의=""`에서 `=` 왼쪽의 `치히로의`는 속성 이름이고, 오른쪽의 `""`는 값이 비어 있다는 뜻이다.
  `행방불명=""`도 같은 구조다. 제목의 뒷부분이어야 할 두 단어가 각각 새로운 속성 이름으로 읽힌다.

  이 페이지의 코드는 그 두 속성을 사용하지 않고, `data-id`의 값인 `'센과'`로 영화를 찾는다.
  내부 목록에는 `'센과 치히로의 행방불명'`이라는 전체 제목이 저장되어 있어 두 값이 다르므로, 카드 이동이 멈춘다.
